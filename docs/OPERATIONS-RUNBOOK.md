# ⚡ xLFr4n // Operations Runbook

## 🇪🇸 Español

El laboratorio sigue ocho puertas. No se considera completa una etapa hasta cumplir su salida.

1. Preparación: VM, red y herramientas disponibles.
2. Autorización: documento y contacto de emergencia registrados.
3. Scope: inclusiones y exclusiones cargadas.
4. Targeting: activos con nombre estable y uno activo.
5. Operación: actividad iniciada deliberadamente por el operador.
6. Evidence: artefactos originales y hashes.
7. Findings: observaciones reproducibles con impacto y remediación.
8. Reporting: revisión humana y entrega.

Cada engagement debe poder volver a un snapshot limpio del laboratorio.

## 🇬🇧 English

The laboratory uses eight gates: preparation, authorization, scope, targeting, operation, evidence, findings and reporting.

A phase is only complete when its evidence exists. The runbook is intentionally procedural so the environment remains predictable instead of becoming a collection of disconnected tools.

Every lab engagement should be recoverable to a known-good snapshot.
